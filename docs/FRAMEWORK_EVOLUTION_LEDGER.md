# Framework Evolution Ledger

**Purpose:** single authoritative record of every framework change made
during C12F development and the closure passes that followed. Each row lets a
reader answer *"why was this framework behavior changed, what evidence
motivated it, and what did that change affect?"* without terminal-log
archaeology.

Timestamps and hashes are recovered from the C12F run's `manifest.json` events
and this session's file writes. Where exact historical metadata is
unavailable it is marked `UNKNOWN`.

Fields per row:
`change_id · timestamp · run_context · problem · evidence · root_cause ·
change_type · files_changed · behavior_before · behavior_after ·
scientific_compute_changed · existing_sci_artifacts_changed · c12f_affected ·
authorization · tests · test_result · backward_compat · prospective_only ·
status`

---
